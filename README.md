# CortexOS · Organization profile

This repository contains the public organization profile and shared presentation assets for [cortexos-dev](https://github.com/cortexos-dev).

- [Organization profile](profile/README.md) — 三个产品入口与组织定位
- [Brand assets and usage](brand/README.md) — 标识、头像、横幅与配色来源
- [cs-ui-web](https://github.com/cortexos-dev/cs-ui-web) — 电脑端工作台（网页 + Mac app）
- [cs-mcp](https://github.com/cortexos-dev/cs-mcp) — CortexOS 的 MCP 接入层
- [cs-app](https://github.com/cortexos-dev/cs-app) — 手机端工作台

The three products share one mark. Its source of truth is `cs-app/client/design/logo` in the [cs-app](https://github.com/cortexos-dev/cs-app) repository; the assets here are application copies of it.

The profile describes publicly available capabilities. Private infrastructure, access credentials and internal deployment details do not belong in this repository.
